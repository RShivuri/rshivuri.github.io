## What I do

- **Backend.** .NET 8 services with Clean Architecture and Minimal APIs: a multi-tenant WhatsApp CPaaS and e-commerce backend on the Meta Cloud API, and a synthetic South African identity, banking (AVS) and civil-registry data API whose output passes real validators (Luhn and all).
- **Enterprise CRM.** Dynamics 365 CE and Dataverse for a payments and ATM business: sales-to-live onboarding, change control, settlement and banking integration, white-label email templates.
- **Release engineering.** An Azure DevOps pipeline that deploys a versioned manifest to QA and then production with a pre-flight check, a service principal and two-person approval. A C# Dataverse SDK harness proves five change-control processes end to end before every release.
- **AI in the loop.** Dataverse, Jira, Postman and SQL wired into Claude Code as MCP servers for read-only forensics before any change; Copilot for boilerplate; synthetic test data designed in conversation and generated by code.
